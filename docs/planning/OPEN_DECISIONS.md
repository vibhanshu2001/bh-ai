## Core retained by conditional review

The review retains one utility engine (subject to signed compatibility) and sole SQLite writer; strict sandboxed renderer/preload; deterministic phrase grammar with established tokenization/Fuse primitives; no trained classifiers/AI; one typed action catalog and workflow format; sequential workflows with simple conditions; separate service/run lifetimes; exact target clarification; no automatic mutation replay; per-chat context row and sequence guards; on-demand diagnostics only; no runtime plugins/daemon/cloud backend. This revision proposes one active workflow initially, staged table migrations and a minimal helper, without weakening those guarantees. Reopen a boundary only through evidence and a documented review.
